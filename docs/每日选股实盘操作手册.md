```bash
# 【推荐】自动用近 1 年滑动窗口,不用手算日期

```

> **三种 pct 用法对比：**
> - **默认（不传）**：in_range 用当天样本算 pct_rank，跟回测 ~50% 重合（**不推荐**）
> - `--pct-range start:end`：指定整段 range，跟回测 100% 一致（验证时用）
> - `--pct-auto`：自动用 `<今天-365天>:<今天>` 滑动窗口，跟回测 100% 一致（**实盘每日用**）

> **为什么需要 `--pct-range`？**
> 回测算 pct_rank 用整段范围的所有信号做样本，daily_picker 默认只用当天样本（结果会差 1 只）。
> 加 `--pct-range` 让 daily_picker 用回测一样的范围算百分位，**选股结果跟回测 100% 一致**。
> 推荐：跑回测用什么 `--start/--end`，daily_picker 就用什么 `--pct-range`。

## 四、下单操作

### 4.1 读取候选股信息

从屏幕输出直接获取：

```
1. SH600416 湘电股份  [MA_CROSS]   MA5/60金叉 gap=2.09%
2. SZ002921 联诚精密  [MA_CROSS]   MA5/60金叉 gap=1.90%
```

### 4.2 确定买入价格

```
1. 打开通达信，找到该股票
2. 查看信号日（输出中标注的日期）收盘价
3. 以「信号日收盘价 × 1.003」附近价格下单（留点滑点余量）
```

> **为什么挂高于收盘价？**
> 回测假设次日开盘买入，实际以次日开盘价成交。
> 信号日收盘价 ≈ 次日开盘价的参考线。
> 挂 1.003 倍是为了确保能成交，不追求买在最低。

### 4.3 下单模板

以湘电股份(SH600416)为例：

```
证券代码：600416（上海A股）
买入方向：买入
买入数量：100股的整数倍（每只股票等权分配资金）
          例：总资金10万 → 每只5万 → 5万÷收盘价=股数（取整百）
买入价格：信号日收盘价 × 1.003
委托方式：市价委托（最优五档）/ 涨停价附近
```

### 4.4 涨跌停股处理

```
❌ 候选股开盘涨停 → 不买入，跳过，顺位选下一只
❌ 信号日已涨停（涨幅9.8%~10%）→ 不买入，跳过
✅ 备选方案：在"备选候选"里选下一只
```

### 4.5 止损规则

```
持仓期间跌幅 ≥ 3% → 当日收盘前止损
止损价 = 买入价 × 0.97
```

**判断方法**：每天收盘后，打开持仓股票，查看当日最低价。
- 如果 最低价 ≤ 成本价 × 0.97 → 触发止损
- 次日开盘前挂单卖出，不恋战

## 五、持仓期间管理

### 5.1 每日检查清单（收盘后15:05前完成）

```
□ 打开持仓股票，查看当日最低价
  → 最低价 ≤ 成本价 × 0.97 → 触发止损，次日开盘卖出
□ 查看持仓股票当日收盘情况
  → 持仓已满N天（看A4输出里的持仓天数）→ 正常到期，次日了结
□ 记录当日收盘点位（用于复盘）
```

### 5.2 到期结算

**发信号日 = Day 0，次日买入，Day N+1 开始计数：**

| 参数配置 | 持仓天数 |
|---------|---------|
| B / A1 / A2 / A3 / A5 | 固定 5 天 |
| A4 / A1+2+3 | 牛市 8 天 / 熊市 3 天（看脚本输出里的市场状态） |

```
到期日收盘前 → 确认是否还有持仓
→ 已触发止损 → 仓位已清，无需操作
→ 正常到期 → 次日开盘卖出
```

### 5.3 动态止盈（A3 参数时）

如果使用 `A3` 或 `A1+2+3` 配置：

```
持仓期间任意一天收盘涨幅 ≥ 6% → 次日开盘卖出（锁定利润）
```

> A4 自适应持仓**不开启**动态止盈，持仓期间让利润奔跑。

## 七、常见问题

### Q1: 今天没有选出任何股票？
**正常现象。** 信号不是每天都有，尤其是熊市期间。查看脚本输出的"沪深300状态"，如果是熊市，候选减少是策略在保护资金。继续等待，直到重新出现信号。

### Q2: 候选股开盘就涨停了买不进去？
**跳过，顺位选下一只。** 在"备选候选"里按顺序选，直到选够2只或候选用完。

### Q3: 持仓期间跌了 2%，要卖吗？
**不卖。** 止损线是 -3%，2% 还在安全范围内。不要提前卖出，让策略自己判断。

### Q4: 持仓期间涨了 10%，要止盈吗？
- **A3 / A1+2+3**：会自动止盈（持仓期间涨超6%→次日开盘卖出）
- **B / A4 / 其他**：没有自动止盈，建议持仓到期。但如果感觉明显滞涨，可以在第3~4天提前卖出

### Q5: 熊市时 A4 显示候选股但实际不会开仓？
**是的，这是设计如此。** A4 的熊市3天持仓指的是"如果开仓后持仓3天"，但选股阶段不屏蔽候选。如果不想在熊市建仓，切换到 `A1` 或 `A1+2` 配置。

### Q6: 资金只有 5 万，能做吗？
**可以。** 每天最多2只，等权分配。最低建议每只不低于1万元，否则5元佣金占比过高。

### Q7: 能程序化自动下单吗？
**目前不支持。** 需要人工在券商APP/软件下单。下一步可研究 TdxQuant 的 send_order 接口对接。

### Q8: 止损后资金如何处理？
**不急于立刻买回。** 等待下一个交易日，按标准流程重新选股。

### Q9: 怎么知道当前用的是哪个参数？
**看脚本输出的标题行：**
```
🎯 每日选股（傻瓜版）  参数配置：A4 - 持仓自适应（近1年最强）
```
每次运行脚本时，第一行就会显示当前 CONFIG 的值。

### 8.1 一键回测脚本

进入工作目录：

```bash
cd D:/Files/workspace-ai/quant
```

**常用命令（5个就够用）：**

| 命令 | 用途 | 耗时 |
|------|------|------|
| `python scripts/run_backtest.py --single A4 --period 近1年` | 快速验证当前最优参数 A4 | ~20秒 |
| `python scripts/run_backtest.py --single A4 --start 2024-01-01 --end 2025-12-31` | 自定义日期范围验证 A4 | ~30秒 |
| `python scripts/run_backtest.py --start 2024-06-01 --end 2025-06-01 --export` | 自定义范围 + 全部8个策略 + 导出CSV | ~5分钟 |
| `python scripts/run_backtest.py` | 跑完整 48 组（8策略 × 6时间段） | 30~50分钟 |
| `python scripts/run_backtest.py --export` | 跑完整 48 组并导出汇总CSV | 30~50分钟 |

### 8.2 参数说明

```
--single    只跑某个策略：B, A1, A2, A3, A4, A5, A1+2, A1+2+3
--period    跑预设时间段：近1年, 近2年, 熊市, 牛市, 熊市反弹, 疫情爆发
--start     自定义开始日期（YYYY-MM-DD）
--end       自定义结束日期（YYYY-MM-DD）
--export    额外导出汇总CSV
--timeout   单组超时秒数（默认900=15分钟）
```

> **优先级**：`--start/--end` > `--period` > 默认全跑
> 三个不能同时混用，`--start` 和 `--end` 必须配对使用

### 8.6 常见问题

#### Q: 跑回测和之前结论对不上怎么办？
1. 先看 `combo_verify_optimized.py` 这个文件有没有改过 → 没改过就说明数据变了
2. 跑 `python scripts/check_data_quality.py` 检查 DuckDB 数据完整性
3. 如果是新增了策略参数（比如增加了 A6），那需要重新跑完整 48 组对比

#### Q: 交割单里 security_id 怎么转成股票代码？
security_id 是 TdxQuant 的数字 ID，可以用 daily_picker_simple.py 的 `--load` 功能查，或者查数据库：

```python
import duckdb
conn = duckdb.connect("D:/Files/workspace-ai/quant/data/quant.duckdb")
df = conn.execute("SELECT security_id, symbol, name FROM security_master WHERE security_id = 1872").df()
print(df)
#       security_id   symbol  name
# 0            1872  SH603...  ...
```

#### Q: 怎么用 Excel 打开交割单看每笔交易？
交割单是标准 CSV 格式，Excel 直接双击就能打开。或者用文本编辑器也可以。推荐用 Excel/WPS 表格打开，能筛选、按股票ID分组统计等。

#### Q: 我想对比 6 个时间段的某只股票表现，怎么做？
1. 跑 `python scripts/run_backtest.py --export`
2. 打开 `data/param_results/trades_B_近1年.csv` 等多个文件
3. 在 Excel 里筛选 `security_id=1872`（举例），对比它在不同时间段的盈亏
