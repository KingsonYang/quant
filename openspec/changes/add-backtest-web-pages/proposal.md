## Why

当前项目已经具备普通回测和策略回测的 CLI 能力，但使用方式仍然依赖脚本和控制台文本输出，面对大批量明细结果时检索、筛选和对比都不方便。现在需要补上一个贴合现有能力的前端查看入口，让回测参数配置、结果浏览和结果对比从“命令行可用”提升到“日常可用”。

## What Changes

- 新增一个面向回测场景的前端页面能力，提供统一入口查看和执行普通回测与策略回测。
- 新增“普通回测”页面，支持录入现有 `backtest-selection` 所需参数，并展示汇总指标、收益分布和逐笔明细。
- 新增“策略回测”页面，支持录入现有 `backtest-strategy` 所需参数，并展示账户级汇总、交易记录和期末持仓信息。
- 新增供前端调用的应用内服务接口，将现有 CLI/领域层输出转换为适合页面展示的结构化结果。
- 明确页面交互中的参数校验、运行中状态、空结果状态和错误提示，避免用户只能回到控制台排查问题。
- 保持现有 CLI 行为不变，前端页面作为新增访问方式，不替代现有脚本入口。

## Capabilities

### New Capabilities
- `backtest-web-ui`: 提供普通回测页与策略回测页，以及页面所需的结构化回测执行与结果展示能力。

## Impact

- 影响应用入口与工程结构，需要在现有 Python 项目中增加 Web 服务/页面层。
- 影响普通回测与策略回测的结果封装方式，需要复用现有领域逻辑并补充面向前端的结构化返回。
- 可能新增前端静态资源、模板或轻量 Web 框架依赖，并补充页面与接口测试。
- 不修改现有 DuckDB 数据模型，不替换现有 CLI 命令。
