## ADDED Requirements

### Requirement: 系统必须提供回测 Web 入口与页面导航
系统 MUST 提供一个可启动的 Web 入口，用于访问回测相关页面，并提供清晰的页面导航，使用户能够在普通回测页面和策略回测页面之间切换，而不需要依赖 CLI 命令。

#### Scenario: 用户访问回测首页后可以进入两类回测页面
- **WHEN** 用户打开回测 Web 应用
- **THEN** 系统 MUST 提供进入普通回测页和策略回测页的可见入口

#### Scenario: 用户在页面间切换时保留明确的当前定位
- **WHEN** 用户从普通回测页切换到策略回测页，或反向切换
- **THEN** 系统 MUST 在导航中明确标识当前所在页面

### Requirement: 系统必须提供普通回测页面用于执行和查看普通回测
系统 MUST 提供普通回测页面，支持录入与现有 `backtest-selection` 能力一致的关键参数，并在执行后展示适合页面浏览的普通回测结果。页面输入 SHALL 至少包含回测区间、持有周期、规则输入、排序参数和可选的 Top N 参数。页面输出 SHALL 至少包含汇总指标、收益分布和逐笔回测明细。

#### Scenario: 用户成功执行普通回测并查看结果
- **WHEN** 用户在普通回测页面提交合法参数
- **THEN** 系统 MUST 执行普通回测并展示汇总指标、收益分布和逐笔回测明细

#### Scenario: 普通回测无命中结果时页面仍可解释
- **WHEN** 用户提交合法参数但普通回测没有命中任何记录
- **THEN** 系统 MUST 返回明确的空结果提示，而不是显示空白页面或未处理错误

### Requirement: 系统必须提供策略回测页面用于执行和查看策略回测
系统 MUST 提供策略回测页面，支持录入与现有 `backtest-strategy` 能力一致的关键参数，并在执行后展示适合页面浏览的策略回测结果。页面输入 SHALL 至少包含回测区间、持有周期、选股规则、持仓上限、单日买入上限、初始资金、单笔仓位比例、止盈阈值和止损阈值。页面输出 SHALL 至少包含账户级汇总、交易记录和期末未平仓信息。

#### Scenario: 用户成功执行策略回测并查看账户结果
- **WHEN** 用户在策略回测页面提交合法参数
- **THEN** 系统 MUST 执行策略回测并展示账户级汇总、交易记录和期末未平仓信息

#### Scenario: 策略回测在期末仍有持仓时页面保留持仓信息
- **WHEN** 策略回测执行完成且回测结束时仍存在未平仓持仓
- **THEN** 系统 MUST 在页面结果中展示这些未平仓记录，而不是仅显示现金余额

### Requirement: 系统必须向页面返回结构化回测结果
系统 MUST 为普通回测页面和策略回测页面提供结构化结果载荷，使页面层不需要解析 CLI 文本输出。结构化结果 SHALL 覆盖页面渲染所需的摘要字段、分布字段、明细字段和错误字段，并保证相同输入下返回结果具有确定性。

#### Scenario: 页面渲染不依赖 CLI 文本
- **WHEN** Web 页面请求普通回测或策略回测结果
- **THEN** 系统 MUST 返回结构化结果，而不是要求页面解析命令行输出文本

#### Scenario: 相同参数重复执行返回一致结果结构
- **WHEN** 用户对同一组普通回测参数或策略回测参数重复提交请求
- **THEN** 系统 MUST 返回字段结构一致且顺序稳定的结果载荷

### Requirement: 系统必须提供页面级参数校验、运行状态和错误反馈
系统 MUST 在页面交互中对参数错误、运行中状态和执行失败提供明确反馈。对于缺失参数、格式错误、领域校验失败或运行异常，系统 MUST 在页面中返回可读的错误提示，而不是仅依赖服务端日志或空白响应。

#### Scenario: 用户提交非法参数时页面显示校验错误
- **WHEN** 用户在普通回测页或策略回测页提交缺失、格式错误或越界的参数
- **THEN** 系统 MUST 在页面中展示明确的错误信息，并指出无法执行的原因

#### Scenario: 回测执行过程中页面给出运行中反馈
- **WHEN** 用户提交合法参数且回测正在执行
- **THEN** 系统 MUST 向用户展示当前请求正在处理的运行中状态

#### Scenario: 回测执行失败时页面显示失败原因
- **WHEN** 回测请求在执行阶段触发领域错误或内部异常
- **THEN** 系统 MUST 返回用户可理解的失败提示，而不是未处理异常页面
