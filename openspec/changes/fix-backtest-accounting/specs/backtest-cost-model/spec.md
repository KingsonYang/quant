## ADDED Requirements

### Requirement: 系统必须按成交事件计算交易成本
系统 MUST 支持配置佣金、卖出印花税、过户费和买卖滑点。买入和卖出成本 MUST 按实际成交金额计算，印花税默认仅对卖出收取，并分别记录毛金额、成本和净金额。

#### Scenario: 买入成本计入现金扣减
- **WHEN** 买入成交并产生佣金、过户费或买入滑点
- **THEN** 账户现金 MUST 扣减成交金额与买入成本之和，交易明细 MUST 保存成本明细

#### Scenario: 卖出成本计入净收入
- **WHEN** 卖出成交并产生佣金、印花税、过户费或卖出滑点
- **THEN** 未结算现金 MUST 增加扣除卖出成本后的净收入，净盈亏 MUST 使用净买入支出和净卖出收入计算

### Requirement: 成本口径必须进入报告指标
系统 MUST 将交易成本纳入现金余额、权益曲线、总收益、年化收益和年度统计，并在报告中标识是否包含成本及所用费率版本。

#### Scenario: 成本开关关闭时保持毛收益兼容
- **WHEN** 使用历史兼容配置且成本模型未启用
- **THEN** 成本 MUST 按零计算，报告 MUST 标记 `costs_included=false`

#### Scenario: 成本开关开启后净收益降低
- **WHEN** 使用相同交易序列分别运行零成本和非零成本配置
- **THEN** 非零成本配置的期末资产 MUST 不高于零成本配置，且成本总额 MUST 可由交易明细加总
