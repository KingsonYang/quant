## ADDED Requirements

### Requirement: 回测期末账户状态必须唯一且可重算
系统 MUST 使用同一份期末账户状态生成摘要、权益曲线最后一点和未平仓交易估值。期末总资产 MUST 等于现金余额加所有未平仓头寸的期末市场价值，且已实现盈亏与未实现盈亏的定义 MUST 与该状态一致。

#### Scenario: 摘要与权益曲线期末资产一致
- **WHEN** 回测区间包含未平仓头寸
- **THEN** 摘要中的现金、市场价值和总资产 MUST 与权益曲线最后一点逐项一致

#### Scenario: 无交易区间仍生成期末权益点
- **WHEN** 回测区间没有产生买入或卖出
- **THEN** 系统 MUST 输出包含起止交易日状态的权益曲线，期末总资产 MUST 等于初始现金

### Requirement: 报告必须保留实际执行配置
系统 MUST 从同一个规范化配置对象生成执行参数、请求快照和摘要字段。报告中的规则数量、日期、仓位、开关和成本配置 MUST 与实际执行值一致。

#### Scenario: 配置序列化往返保持一致
- **WHEN** 回测配置被写入 JSON 后再读取
- **THEN** 规范化配置的字段和值 MUST 保持一致，缺省字段使用版本化默认值

#### Scenario: 规则数量反映实际规则集合
- **WHEN** 回测执行使用一组规范化规则
- **THEN** 请求快照和摘要中的规则数量 MUST 等于该规则集合的数量
